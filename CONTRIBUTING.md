# Contributing to StudioUI public information

This repository advertises StudioUI and hosts public product information. It is
not the internal development repository or the plugin source distribution.
Product development is maintained separately in a private repository.

**Product site:** [studioui.ai](https://studioui.ai)

## Contributions here

- Suggest corrections to public documentation and product descriptions.
- Report a product issue with steps to reproduce, using only non-sensitive details.
- Suggest features or improvements to public-facing materials.

For documentation pull requests, branch from `main`, keep the change focused and
describe what changed. Do not submit internal implementation, operational records,
credentials or private development material to this public repository. Product-code
contributions require a separately agreed development location and workflow.

## Reporting security issues

Do not post vulnerabilities, credentials or private logs in public issues. Contact
the project privately through [studioui.ai](https://studioui.ai).
